# Luciole

Luciole is the Noctalia file manager. Mabox Noctalia CE opens it from the root menu, from `W-f`, and from the folders in Places and the panels.

Tips:

- [Scripts](luciole-scripts.md): extra actions in the right-click menu, like converting files.
- [Colours](luciole-colours.md): how Luciole follows the Noctalia theme.

To use Luciole as the main file manager with Places as its sidebar, see [Places](places.md#together-with-luciole).
